# HTML/CSS-inlämning – Tegel Consulting

Inlämningsuppgift i kursen **HTML och CSS** på [IT-Högskolan](https://www.iths.se/).

Uppgiften går ut på att bygga en **statisk webbsida** som publiceras med **GitHub Pages**. Sidan ska vara en **pixelnära kopia** av den referensbild/design som läraren delade ut — samma layout, typografi, färger och innehåll, kodad med HTML och CSS.

Live: [linneaegner.github.io/htmlcss-inlamning](https://linneaegner.github.io/htmlcss-inlamning)
